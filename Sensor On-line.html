Ajuda — Como Utilizar o aplicativo[span_125](start_span)[span_125](end_span)

1. Identificador de sensor. Analisa um sensor desconhecido.
Ex: Digite a resistência em kΩ e a temperatura em °C do mesmo.[span_126](start_span)[span_126](end_span)
2. Consultar sensor de fábrica.
Ex: LG → Sensor amb. interno 1k e 25°C retorna 5k.[span_127](start_span)[span_127](end_span)
3. Sensor paralelo. Analisa os sensores que não são originais.[span_128](start_span)[span_128](end_span)
4. Sensor Original. Analisa os sensores de fábrica.[span_129](start_span)[span_129](end_span)
5. Selecionar fabricante. Analisa cada sensor original de acordo com seu modelo.[span_130](start_span)[span_130](end_span)
6. Alterar / Restaurar Parâmetros. Permite atualizar as informações técnicas do sensor.[span_131](start_span)[span_131](end_span)
