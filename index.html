Ajuda — Como Utilizar o aplicativo

1. Identificador de sensor. Analisa um sensor desconhecido.
Ex: Digite a resistência em kΩ e a temperatura em °C do mesmo.
2. Consultar sensor de fábrica.
Ex: LG → Sensor amb. interno 1k e 25°C retorna 5k.
3. Sensor paralelo. Analisa os sensores que não são originais.
4. Sensor Original. Analisa os sensores de fábrica.
5. Selecionar fabricante. Analisa cada sensor original de acordo com seu modelo.
6. Alterar / Restaurar Parâmetros. Permite atualizar as informações técnicas do sensor.
